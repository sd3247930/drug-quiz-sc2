# 药品管理相关法规知识竞赛刷题系统

生产二部法规知识竞赛刷题网页。**单文件、零依赖、无需安装**，双击就能用，也可放在任意静态托管（GitHub Pages / 内网服务器）上给同事一起用。

题库共 **300 题**：单选 190 题、多选 110 题。

> 在线访问：<https://sd3247930.github.io/drug-quiz-sc2/>

---

## 功能

- **顺序练习**：从上次进度接着做，关掉网页再打开也不丢
- **随机练习**：打乱 300 题顺序，避免按顺序背题造成"假掌握"
- **错题练习**：只做错题本里的题，答对自动移出
- **错题本**：查看题干、正确答案、累计答错次数，也可手动移出
- **统计**：总题数、已答题数、最近一次正确率、错题数、累计作答次数、单选 / 多选分项正确率
- **清空记录**：二次确认后一键归零，重新开始

判分规则与正式竞赛一致：**多选题选项完全一致才算对，多选、少选、错选都算错**。

## 关于数据

练习进度、错题本、统计**只保存在你自己设备的浏览器里**（localStorage），不会上传到任何服务器。

- 换手机、换浏览器、清除浏览器数据后，记录会清零
- 页面里有「清空所有记录」按钮可以主动重置
- 如果在同一台设备上访问过本账号下的其他 Pages 应用，它们的本地数据互相独立，键名分别隔离

## 常见问题

**进度会同步到其他设备吗？**
不会。目前没有账号体系，数据只在本机浏览器里。

**刷新后进度会丢吗？**
不会，每答完一题立即保存。

**错题什么时候会消失？**
在错题练习中把它答对（自动移出），或在错题本里点「移出错题本」。

**正确率怎么算的？**
按每题**最近一次作答**计算，所以错题重练答对后正确率会提高；「累计作答次数」单独反映练习量。

## 技术说明

- 纯单文件 HTML + 原生 JavaScript + CSS，**无任何第三方依赖、无构建步骤**
- 题库内嵌在 `index.html` 里，因此 `file://` 双击打开也不会被浏览器的跨域限制拦住
- 全部使用相对路径，部署在根目录或子目录都能正常工作
- 渲染一律使用 `textContent` / `createElement`，不使用 `eval` 与 `innerHTML` 插入数据
- 本地数据读取失败时自动回退默认值；浏览器禁用本地存储时退化为内存模式，页面依然可用
- 手机适配：按钮最小高度 48px、字号 16px、选项点击区域不小于 44px

### 修改题库

打开 `index.html`，搜索 `const QUESTION_BANK`，每题一行：

```js
{"type":"单选","question":"题干","options":["A. 选项一","B. 选项二","C. 选项三","D. 选项四"],"answer":["C"]}
```

`type` 填 `"单选"` 或 `"多选"`；`answer` 单选写一个字母，多选写多个字母（按字母升序）。改完保存、刷新网页即可生效。
