# 药品管理相关法规知识竞赛刷题系统

生产二部法规知识竞赛刷题网页。**单文件、零依赖、无需安装**，Windows 上双击就能用；Android 上打开网址即可，点右上角 **「📲 安装」** 还能直接下载独立 APK（无地址栏、断网可用）。

题库共 **300 题**：单选 190 题、多选 110 题，**每题都带 AI 解析与法律条文依据**。

> 在线访问：<https://sd3247930.github.io/drug-quiz-sc2/>

---

## 版本说明（本仓库是"单文件离线版"）

| 版本 | 形态 | 能力 | 在哪 |
| --- | --- | --- | --- |
| **单文件离线版**（本仓库） | 一个 `index.html` + PWA 资源 | 顺序 / 随机 / 错题练习、解析与法条、背题模式、错题本、统计、**答题卡题号矩阵**、**进度导出 / 导入**、**我的笔记**、清空；可离线、可安装到手机主屏 | 本仓库根目录 |
| 服务端版（Flask） | `app.py` + Jinja2 + JSON 数据 | 在离线版基础上增加**自由选题练习**（按题型 / 状态 / 关键词筛选后自定义组卷）、收藏、局域网多设备共享进度 | 项目源目录 `服务端版/`（需 Python 3 运行，不在本仓库） |

两版题库由同一份数据生成（300 题，含 AI 解析与法条依据），不会出现内容不一致。
**三版进度格式互通**：离线版、服务端版、Android 版导出的进度 JSON 可以互相导入。

## 功能

- **顺序练习**：从上次进度接着做，关掉网页再打开也不丢
- **随机练习**：打乱 300 题顺序，避免按顺序背题造成"假掌握"
- **错题练习**：只做错题本里的题，答对自动移出
- **错题本**：查看题干、正确答案、累计答错次数，也可手动移出
- **解析与法条**：提交答案后自动展开「AI 解析」与对应法律条文，明白为什么选这个答案
- **背题模式**：直接显示答案与解析、不判题，适合快速过一遍
- **统计**：总题数、已答题数、最近一次正确率、错题数、累计作答次数、单选 / 多选分项正确率
- **答题卡矩阵**：按 5 列排布 300 个题号，未答灰 / 答对绿 / 答错红 / 收藏 ★；点题号直接跳到该题
- **进度导出 / 导入**：导出成 JSON 文件做备份或换设备迁移；导入时可选**覆盖**或**合并**（与 App、服务端版互通）
- **我的笔记**：每题在解析下方写自己的备注（错因、易混点），停止输入或离开输入框自动保存
- **清空记录**：二次确认后一键归零，重新开始
- **离线可用**：支持安装到手机主屏幕（PWA），断网也能打开

> 自由选题练习（按题型 / 状态 / 关键词筛选组卷）与收藏功能在**服务端版**里。

判分规则与正式竞赛一致：**多选题选项完全一致才算对，多选、少选、错选都算错**。

## 使用方法

### 在线使用（推荐）

直接用手机或电脑浏览器打开：<https://sd3247930.github.io/drug-quiz-sc2/>

**想装成 Android App**：点右上角 **「📲 安装」** → 面板里点 **「📥 下载应用（APK）」**，浏览器会直接下载安装包（不会跳转到 GitHub 页面）。

> 固定直链（永远指向最新版，可直接转发给同事）：
> <https://github.com/sd3247930/DrugQuiz-SC2-Android/releases/latest/download/DrugQuiz-SC2.apk>

装好后主屏出现「药品法规刷题」图标，打开无地址栏、断网能用。想把网页上的进度搬进 App：先在网页「导出进度」保存文件，再在 App「设置 → 进度备份 → 导入进度」导入。

不想装 App 也可以只用网页：浏览器菜单 →「添加到主屏幕」（这种是快捷方式，仍跑在浏览器里）。

### 本地使用

下载 `index.html`，双击即可。不需要 Node.js、Python 或任何运行环境，断网也能用。

> 说明：本仓库为发布版本（只有运行所需文件）。需要"添加一行题目就重新生成"的完整工程（题库导入脚本、自动验收脚本）时，请使用项目源目录版本。

## 关于数据

练习进度、错题本、统计**只保存在你自己设备的浏览器里**（localStorage），不会上传到任何服务器。

- 换手机、换浏览器、清除浏览器数据后，记录会清零
- 页面里有「清空所有记录」按钮可以主动重置
- 如果在同一台设备上访问过本账号下的其他 Pages 应用，它们的本地数据互相独立，键名分别隔离

## 常见问题

**进度会同步到其他设备吗？**
不会。目前没有账号体系，数据只在本机浏览器里。

**刷新后进度会丢吗？**
不会，每答完一题立即保存。

**错题什么时候会消失？**
在错题练习中把它答对（自动移出），或在错题本里点「移出错题本」。

**正确率怎么算的？**
按每题**最近一次作答**计算，所以错题重练答对后正确率会提高；「累计作答次数」单独反映练习量。

**解析太长、想直接看答案？**
打开答题页的「背题模式」开关，会直接显示答案与解析，不判题。

## 技术说明

- 纯单文件 HTML + 原生 JavaScript + CSS，**无任何第三方依赖、无构建步骤**
- 题库内嵌在 `index.html` 里，因此 `file://` 双击打开也不会被浏览器的跨域限制拦住
- 全部使用相对路径，部署在根目录或子目录都能正常工作
- 渲染一律使用 `textContent` / `createElement`，不使用 `eval` 与 `innerHTML` 插入数据
- 本地数据读取失败时自动回退默认值；浏览器禁用本地存储时退化为内存模式，页面依然可用
- 手机适配：按钮最小高度 48px、字号 16px、选项点击区域不小于 44px
- PWA：`manifest.json` + `sw.js` + `icons/`，可安装到手机主屏幕；`file://` 下会自动跳过注册，不影响双击使用
- 文件体积约 410 KB（其中大部分是 300 道题的解析与法条原文）

### 修改题库

打开 `index.html`，搜索 `const QUESTION_BANK`，每题一行：

```js
{"type":"单选","question":"题干","options":["A. 选项一","B. 选项二","C. 选项三","D. 选项四"],"answer":["C"]}
```

`type` 填 `"单选"` 或 `"多选"`；`answer` 单选写一个字母，多选写多个字母（按字母升序）；`explanation` 与 `law` 分别是解析与法条。改完保存、刷新网页即可生效。
